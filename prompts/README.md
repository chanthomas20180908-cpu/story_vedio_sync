# 混搭故事生成器

用两份原文素材 + 一个故事灵感，生成连环画字幕故事。

---

## 核心思路

生成器不发明情节，不自造意象，不模仿风格。它做的是：

- **情节**：从原文里找事件原型，移植、变形、嫁接
- **句型**：直接套用西游记的句式骨架
- **意象**：直接搬入洛夫克拉夫特的具体细节

你提供方向（故事灵感），生成器从素材里长出故事。

---

## 文件

```
prompts/
└── generator_v1.md    生成器模板（素材 + 规则 + 输出格式）
```

模板内嵌：
- 素材 A：吴承恩《西游记》第五十四回（句型来源）
- 素材 B：洛夫克拉夫特《大衮》《异乡人》（意象来源）

---

## 用法

### 1. 写故事灵感

灵感是方向，不是大纲。1-4 句话，只说"发生了什么"，不规定细节、节奏、帧数。

示例：
```
唐僧师徒经过女儿国。子母河里有比女儿国更古老的东西，它一直在等人来。
女王知道它，全城的女人都知道。但没有人说出来。
师徒四人离开了，但有什么跟着走了，或者有什么留下来了。
```

### 2. Spawn 生成器 Subagent

在 Claude Code 里，spawn 一个新 subagent，prompt 如下：

```
请读取文件：
/Users/test/code/Python/AI_vedio_demo/story_vedio_sync/prompts/generator_v1.md

将文件中的 {SEED} 替换为以下故事灵感：
[在此填入灵感]

严格按照文件中的全部规则，生成完整连环画字幕故事。
只输出 JSON 数组，格式：[{"id": "A01", "caption": "..."}, ...]
不要任何前言、解释、总结。
```

### 3. 评估输出

检查三个维度：

| 维度 | 合格标准 |
|------|---------|
| 情节根源 | 每个事件能在某一原文里找到原型 |
| 句型 | 动词先行或说书开头，无解释句 |
| 意象 | 核心细节来自原文，非自造 |

常见问题：叙事视角穿帮（描述角色无法知道的信息），换灵感或调整规则重跑。

---

## 迭代方式

| 想改什么 | 怎么做 |
|---------|--------|
| 故事方向 | 换灵感，重新 spawn |
| 生成风格 | 修改 `generator_v1.md` 的规则部分 |
| 换素材 | 替换模板里的素材 A 或素材 B |
| 保留某一版结果 | 将 JSON 输出另存为 `output/vX.json` |

---

## 与直接问 Claude Code 的区别

Subagent 冷启动，不知道当前对话的任何上下文，只按模板规则执行。
这是"固定生成器"的隔离机制——模板不变，每次结果风格一致。
