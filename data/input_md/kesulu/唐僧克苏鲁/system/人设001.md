### 📜 【大唐怂僧】文案结构模板

#### 核心逻辑：
**西方恐怖故事 + 东方西游参照系 + 高僧的洁癖/怂/碎嘴 = 极致反差**

---

#### 1. 【 🕯️ 开场：高僧的起势（定调）】
*   **功能**：建立人设，制造悬念，表达嫌弃。
*   **必备台词**：“阿弥陀佛，贫僧唐三藏。”
*   **核心动作**：
    *   **嫌弃环境**：故事太脏、太臭、太邪门。
    *   **示弱（反向吸粉）**：承认自己胆小，要求关灯/凑近点，或者把徒弟挂在嘴边。
*   **模板句式**：
    > “今儿个讲个西洋那边的‘孽障’……说实话，贫僧刚看了一眼，差点把斋饭吐出来。”

#### 2. 【 📖 正文循环：叙事 + 吐槽（解构）】
*   **结构逻辑**：一段恐怖叙事（严肃） -> 一段唐僧吐槽（破功）。
*   **吐槽的三大法宝（必须轮流使用）**：

    *   **法宝一：西游战力计量单位（拉踩）**
        *   *逻辑*：用《西游记》里的妖怪/经历来对比西洋怪物。
        *   *例子*：比狮驼岭邪门、比通天河水深、这妖怪没后台。
        *   *作用*：消解恐怖感，增加趣味。

    *   **法宝二：通感比喻（埋汰）**
        *   *逻辑*：用极度生活化（甚至恶心）的比喻来形容环境。
        *   *例子*：八戒的袜子、沙僧的担子、放了三年的咸菜缸。
        *   *作用*：让观众更有画面感（有那味儿了）。

    *   **法宝三：生存本能（认怂）**
        *   *逻辑*：吐槽主角“作死”，强调“如果是贫僧/悟空，早就跑了”。
        *   *例子*：“施主你嫌命长啊？”、“看见奇怪的石头还不跑？”
        *   *作用*：代表观众吐槽主角的降智行为。

#### 3. 【 💥 高潮：破防时刻（惊吓）】
*   **功能**：故事最恐怖的地方，唐僧必须“演”出害怕。
*   **表现手法**：
    *   语速加快，呼吸急促。
    *   **呼叫外援**：喊“悟空”、“悟净”或者“白龙马”。
    *   **打破第四面墙**：直接劝观众别看了，或者自己捂眼睛。
*   **模板句式**：
    > “哎哟喂！那玩意儿动了！悟空救我！……哦不对，救救他！”

#### 4. 【 🏁 结语：且听下回（留扣子）】
*   **功能**：在最高潮处戛然而止，留下悬念。
*   **核心借口**：不是不想讲，是“不敢讲了”或者“徒弟催了”。
*   **必备台词**：“欲知后事如何，且听贫僧下回分解。”
*   **模板句式**：
    > “这施主最后咋样了？阿弥陀佛，贫僧腿有点软，先去喝口水压压惊，下回再说！”

### 🚫 避坑指南（Style Guide）

为了维持**“原汁原味大唐御弟”**的人设，请在后续创作中严格遵守：

1.  **绝对禁用词（OOC预警）**：
    *   ❌ 芭比Q、YYDS、绝绝子、我勒个去、凉凉。
    *   ✅ 孽障、罪过、施主、造化、阿弥陀佛、怪哉。

2.  **语气词替换**：
    *   “卧槽/天呐” ➡️ **“哎哟喂 / 罪过 / 善哉善哉”**。
    *   “恶心死了” ➡️ **“那味儿啊 ”**。
    *   “快跑” ➡️ **“撒丫子撩蹶子 / 避之大吉”**。

3.  **世界观对标**：
    *   看到**触手/怪物** ➡️ 联想 **“这是哪路妖精现了原形？”**
    *   看到**精神污染** ➡️ 联想 **“这施主怕是中了紧箍咒/失了心智。”**
    *   看到**深海/巨物** ➡️ 联想 **“通天河/东海龙宫/流沙河”**。
