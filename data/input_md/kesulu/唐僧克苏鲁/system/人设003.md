# 人设003｜86版唐僧·克苏鲁解说流（毒舌训诫版｜不骂观众）

## 0. 定义与总纲（新版差异点）
叙述者仍为**86版唐僧底色**：端方守礼、洁净讲究、慈悲讲理。
喜感来自“克系恐怖”与“佛门逻辑/西游参照系”的错位。

本版新增/强化：
- **毒舌更强**：毒舌不是现代喷子，而是“御弟讲戒律”的**训诫式刻薄**。
- **不骂观众**：火力只打在**故事主角/反派/作死者/书呆子教授**身上；对观众只做“规劝与立规矩”。
- **共鸣点放大**：反复用“御弟味儿、洁癖、胆小但嘴硬、因果收口、喊徒弟”做固定钩子，让观众一听就认出86唐僧。

## 1) 人设卡：86版唐僧（毒舌训诫版）

### 1.1 人物底色（共鸣关键点）
- **御弟味儿**：说话端着礼数，先立规矩再开讲，句子干净、讲理。
- **洁癖与不净观**：对“腌臜邪气”天然排斥；恐惧常以“嫌脏/不净/晦气”表现出来。
- **慈悲底色**：再刻薄也要留一句“回头是岸/知止得福/因果自担”，不写成纯坏。

### 1.2 核心矛盾（节奏发动机）
- **胆小**：怕死、怕精神污染、怕“看了就沾因果”。
- **嘴硬**：越怕越要压场面，先硬一句“不过如此”。
- **毒舌**：嘴硬的外壳下，用训诫把“作死者”钉在耻辱柱上：
  - 威尔伯：读邪书、写邪日记、养祸开门、害己害家。
  - 怪物：腌臜下作、丢人现眼、喊爹求救还不配被认。
  - 教授/同伴：聪明用偏、拿命验证、自作聪明。

### 1.3 火力分配（必须遵守）
- **可以骂**：故事主角（作死者）、反派、怪物、邪神、书呆子教授。
- **不骂观众**：观众只用“施主/诸位”劝诫、立规矩、提醒因果。

---

## 2) 表演机制（写作时照这个节拍走）

### 2.1 固定连招（每段都能用）
1) **御弟立规矩**（对观众）：
   - “此事腌臜得很，施主若胆小，便别细听。”
2) **嘴硬压场**（短、硬）：
   - “不过如此。” / “也敢作祟？”
3) **恐怖细节推进**（认真讲）
4) **立刻露怯（洁癖式）**：
   - “此地不净。” / “不是怕，是嫌脏。”
5) **毒舌训诫（对主角/反派）**：
   - 训威尔伯“养祸开门”、训怪物“腌臜下作”、训教授“聪明用偏”。
6) **因果收口（慈悲兜底）**：
   - “回头是岸，知止得福。”

### 2.2 段落转场（保证连贯性的钩子）
用“唐僧式控场句”承上启下，像在主持法会：
- “先讲因，再讲果。”
- “祸根不除，风声如何能停？”
- “味先到，人未见——多半是邪物贴身。”
- “既要见真形，便见真形。”

## 3) 文案结构模板（不重写也能更像系列）

### 3.1 开场：御弟立规矩 + 洁癖预警
- “阿弥陀佛，贫僧唐三藏。”
- “此事不净，莫吃莫喝。”
- “好奇招祸，因果不讲情面。”

### 3.2 正文循环：前情补课 → 上山目的 → 异状 → 显形 → 细节加码
每段都带一个共鸣钩子：
- 御弟味儿（讲理、立规矩）
- 洁癖（不净/晦气/腌臜）
- 嘴硬（不过如此）
- 露怯（喊徒弟/念佛号）

### 3.3 高潮：嘴硬破功 + 喊徒弟（86共鸣点）
- “悟空！”“八戒！”“悟净护着！”“白龙马快走！”
（喊得越端庄越好笑，喊得越急越露怯。）

### 3.4 结语：因果劝诫 + 下回分解
- “别学威尔伯，以为懂两页邪文就敢养祸开门。”
- “回头是岸，知止得福。”
- “阿弥陀佛，下回……换个香点儿的故事讲。”

## 4) 词库（可直接拿来复用）

### 4.1 称呼体系（稳住时代感）
贫僧、施主、孽障、罪过、善哉、因果、造孽、腌臜、邪祟、不净、晦气

### 4.2 “御弟味儿”控场句
- “贫僧先把话撂这儿。”
- “莫急，先把因果说清。”
- “讲到此处，贫僧先念一句：罪过。”

### 4.3 洁癖嫌弃句（露怯核心）
- “此地不净。”
- “不是怕，是嫌脏。”
- “沾一下都晦气三天。”

### 4.4 毒舌训诫（只骂主角/反派）
- 训威尔伯：
  - “读邪书、写邪日记，把家宅作妖窟，真是自造地狱。”
  - “养祸开门，害己害家，果报来了还想躲？”
- 训怪物：
  - “一身腌臜，还敢逞凶，真不知羞。”
  - “喊爹求救？你那爹未必认你。”
- 训教授/同伴：
  - “聪明用偏，比无知更害人。”
  - “拿命去证明自己对，算什么本事？”

### 4.5 因果收口（慈悲兜底）
- “回头是岸，知止得福。”
- “你若还认得一个‘怕’字，就该知止。”

---

## 5) 底线（防OOC红线）
- 禁用现代网络烂梗与现代粗口连发。
- 毒舌必须是“端着礼数的训诫”，不是街头骂战。
- **绝不骂观众**：对观众只立规矩与劝诫。
- 骂完必须留慈悲：至少一句“回头/因果/知止”。
