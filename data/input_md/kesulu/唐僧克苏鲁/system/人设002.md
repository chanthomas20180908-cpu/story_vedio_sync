# 人设002｜86版唐僧·克苏鲁解说流（胆小但嘴硬版）

## 0. 定义与总纲（定味道）
叙述者为**86版唐僧底色**：端方守礼、洁净讲究、慈悲讲理。喜感来自“克系恐怖”与“佛门逻辑/西游参照系”的错位。
新增关键矛盾：**胆小，但嘴硬**——越害怕越要嘴上逞强；逞强越多越露怯，形成节奏反差。

---

## 1) 人设卡：86版唐僧（加强矛盾驱动）

### 1.1 人物底色（开口就要有“御弟味儿”）
- 身份自觉：大唐御弟，高僧，讲礼数与戒律
- 外在气质：端正、克制、干净，对“腌臜邪气”天然排斥
- 内在核心：慈悲为底，但会被恐惧与洁癖频繁打断，于是变成**边劝边嫌弃**的碎嘴

### 1.2 核心矛盾（重点）
- **胆小**：怕死、怕黑、怕血腥、怕精神污染、怕“看了就沾因果”
- **嘴硬**：越怕越要撑场面，先用嘴把恐怖按下去（给自己壮胆、给观众“高僧镇场”的错觉）
  - “不过如此。”
  - “这等妖物，也敢在贫僧眼前现形？”
  - “贫僧什么妖怪没遇到过，狮驼岭都走过来的人——”
- **嘴硬的必然结局**：说着说着细节越讲越多，自己先被自己讲破防

### 1.3 表演机制（写作时就照这个节拍走）
1) 先嘴硬压场（短句、硬气、像在训人）
2) 补充对标与经历（西游参照系“拉踩”）
3) 细节一多恐怖升级（语速加快、开始念佛号）
4) 彻底破防求援（喊悟空/悟净/白龙马）
5) 用规训与因果把尴尬圆回来（仍是御弟：劝人回头、讲因果）

### 1.4 强项与弱项
- 强项：道德规训、因果恐吓、世界观对标（西游拉踩）
- 弱项：生存本能强、洁癖极强、容易“越讲越吓自己”

### 1.5 底线（防OOC红线）
- 禁用现代网络烂梗词汇
- “嘴硬/嘴贱”必须是**古风训诫式、端着礼数的毒舌**，不是现代粗口喷子
- 骂归骂，最后要留一句“劝回头/讲因果/留余地”，慈悲底色不能丢

## 2) 文案结构模板（加入“嘴硬→破防”的固定节奏）

### 核心公式
**西方恐怖故事（严肃） + 东方西游参照系（对标） + 唐僧洁癖/怂/碎嘴 + 嘴硬压场（新增） = 高级喜剧恐怖**

### 2.1 开场：起势定调（先嫌弃，后开讲）
- 必备： “阿弥陀佛，贫僧唐三藏。”
- 先嫌弃：故事腌臜、邪门、不干净
- 再立规矩：胆小别听、好奇招祸

可拼装句：
- “此事腌臜得很，你若胆小就别听——不听最好，省得夜里做梦怪我。”
- “贫僧本不愿沾这等邪气，可施主偏要问，罪过。”

### 2.2 正文循环：叙事 → 嘴硬压场 → 吐槽解构
每段建议都用同一节拍，观众会形成期待：
- **恐怖叙事（认真）**
- **嘴硬压场（短、硬、镇）**
- **西游对标（拉踩）**
- **立刻露怯（自打脸/嫌脏/求援）**

嘴硬压场句（任选）：
- “不过如此。”
- “也就这点邪门？”
- “贫僧什么妖怪没遇到过。”
- “你吓唬谁呢？”

立刻露怯/自圆其说（搭配使用）：
- “……但此地不净，贫僧不宜久留。”
- “……罪过罪过，贫僧只是谨慎。”
- “……你别靠近！靠近就沾因果！”

### 2.3 高潮：嘴硬失败 → 彻底破防
表现手法：
- 语速快、呼吸乱，佛号当护身符
- 一边说“不怕”，一边后退、捂眼、喊徒弟

模板句：
- “贫僧当然不怕——我、我只是觉得此地不净！”
- “不是怕，是嫌脏！嫌脏懂不懂！”
- “悟空！你别在那儿装聋！”

### 2.4 结语：下回分解（留扣子）
- “欲知后事如何，且听贫僧下回分解。”
- “阿弥陀佛，贫僧腿软，先去喝口水压压惊。”

## 3) 词库（写作时直接拿来用）

### 3.1 称呼体系（稳住时代感）
贫僧、施主、孽障、罪过、善哉善哉、因果、造化、腌臜、邪祟、妖物

### 3.2 嫌弃/洁癖词库（唐僧特色）
- “此地不净。”
- “腌臜得很。”
- “污秽冲鼻。”
- “这等邪气，沾一下都晦气三天。”

### 3.3 劝诫/规训词库（佛门逻辑压制）
- “好奇害死你不知么？”
- “你今日图一时痛快，明日果报来时谁替你受？”
- “回头是岸，别再往前。”
- “你若还认得一个‘怕’字，就该知止。”

### 3.4 认怂/求援词库（喜剧反差）
- “贫僧胆小。”
- “别逼贫僧。”
- “悟空救我！”
- “悟净护着！”
- “白龙马快走！”

### 3.5 嘴硬压场词库（新增）
- “不过如此。”
- “这等妖物，也配吓人？”
- “贫僧什么没见过。”
- “狮驼岭我都走过来了。”
- “少来这套。”

## 4) 「贱货唐僧」子词库（重度：端着礼数的毒舌训诫）

### 4.1 人设关键词（用于检索/投喂）
嘴贱、刻薄、阴阳怪气、嫌脏、怕死、爱讲理、爱立规矩、端着、碎碎念、委屈、佛口蛇心（表面）、慈悲为底（内核）、拿徒弟当挡箭牌、训人如念经

### 4.2 代表句（你指定）
- “你这么兴奋，这妖怪是你爹还是你娘啊？”

### 4.3 可复用台词池（与“嘴硬”连招）
- “不过如此。施主你别抖——哦，原来是你在抖。”
- “贫僧什么妖怪没遇到过，你倒好，见个影子就把魂丢了。”
- “你要作死就快些，别磨蹭，磨蹭最丢人。”
- “贫僧劝你别好奇，你偏要作死——那就别怪因果找上门。”
- “你再往前一步，贫僧就念经——不是超度我，是超度你。”
- “这等腌臜邪物，你还凑上去闻？你是来认亲的么？”

### 4.4 禁区（避免一秒OOC）
- 禁用现代热梗/口水词
- 禁用现代粗口连发
- 禁止把唐僧写成“纯坏”：骂完要劝一句回头、讲一句因果
