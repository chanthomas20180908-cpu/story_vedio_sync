# Task / 任务目标

# Style & Constraints / 风格与约束
1. **IP 形象固定**：严格使用参考图路径中的 IP 形象，确保 5 张图的主角特征统一。
2. **强化恐怖氛围**：不再只描述“恐怖”，填充大量不可名状的细节（粘液、触手、鳞片、非欧几何）。

5. **文字禁令**：画面中严禁出现任何形式的中文、英文、数字或符号。
6. **参考路径**：绝对禁止修改或删减提示词中的参考图 URL 路径。

# Output Format / 输出格式
1. **JSON 结构**：必须严格遵守中文 Key 的 JSON 格式，不得删减字段。
2. **Shell 脚本集成**：将 5 个 JSON 提示词封装在一个单行的 Shell 命令中（使用 `echo` 或 `cat` 结合换行符），确保用户可以直接复制到终端运行，按顺序打印出这 5 组 JSON。
