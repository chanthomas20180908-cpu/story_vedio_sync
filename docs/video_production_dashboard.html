OPT
001

工作流重设计 · 原子化拆镜 + 分层管线

触发：HappyHorse 四轮测试全部失败 创建：2026-06-03 依据：happyhorse_video_tests_20260525.html
执行中
根因：这是工作流设计问题，不是模型问题。4 次测试全失败的共同原因是用单条生成调用承担了导演的全部工作——把合成层的任务压给了生成层。模型没有被错误使用，而是被错误期待。

问题诊断

P1 · Prompt 架构失调
  • 保持不变 × 3 把模型锁死，运动空间关闭，只能做最保守的镜头推拉
  • 5 个同时进行的动作目标，超出模型动作带宽
  • 风格 + 内容 + 负向描述混写，核心运动信号被稀释
P2 · 参考图策略错误
  • r2v 是素材池，不是分镜时间轴
  • 全景、近景、特写、道具混传同一条 r2v
  • 模型把多图融合成新画面，而不是按描述执行分镜
P3 · 镜头没有原子化
  • HH-004：5 秒内同时要求嘴动 + 经卷 + 袈裟 + 宫灯 + 墨影共 6 个动作
  • 这是 6 层合成片，不是一个镜头
  • 任何现有 i2v / r2v 模型都无法可靠完成
P4 · 模型路由错误
  • 八戒影子逃逸 = 所有 i2v 最难的动作类型之一
  • 影子独立于身体运动是合成层任务，不属于生成层
  • HappyHorse 对此无控制能力；Seedance / Kling 单条 prompt 也不能稳定完成

Prompt 正确架构

维度❌ 当前错误模式✓ 正确模式
结构公式 风格 + 保持不变×3 + 5 个动作 + 负向×4 [风格锚 ≤5词] + [唯一运动焦点] + [镜头状态] + [≤2 关键负向]
运动目标 人物、经卷、衣物、宫灯、墨影同时要求 每条只承载 1 个核心动作，时长 2–3 秒
锁定语言 "保持不变""不要改变构图" "镜头固定"——只锁摄像机，不锁内容
示例重写 天书奇谭手绘风。子母河水面黑色墨影缓慢向四周晕开，水波轻荡。镜头固定。不写实化。

专业分层管线（2025–2026 业内标准）

Layer 1 · 生图层
Midjourney / FLUX / SD
关键帧 · 风格参考 · 角色定稿 · 动作参考图包
Layer 2 · 生视频层（按镜头类型路由）
氛围 / 环境动效
→ HappyHorse r2v（低成本，单主体，单动作）
角色 + 一致性要求高
→ Seedance 2.0（多路输入，跨镜头人物锁定）
复杂动作 / 强导演感
→ Kling 3.0 / Runway Gen-4
Layer 3 · 合成层
DaVinci / After Effects / CapCut
影子遮罩分离 · 经文游动特效 · 嵌 SRT 字幕 · 音效
后期独占效果
影子形变 · 墨迹粒子 · 多镜头拼接节奏

核心原则（业内）：Seedance 作为生成引擎，Runway 负责时间轴编辑和后期。生成层提供风格和动作原料；合成层负责导演控制。
