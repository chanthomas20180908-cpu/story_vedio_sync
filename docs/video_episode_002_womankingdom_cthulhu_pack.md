# 视频 002 生产包：女儿国旧日神胚胎事件

## 1. 核心定位

- 标题：唐僧念错一页经，女儿国开始集体怀上旧日神
- 混搭：西游记女儿国 x 克苏鲁 x SCP 收容档案 x 生化寄生
- 栏目：混搭档案
- 形式：伪纪录片事故复盘
- 核心钩子：女儿国的人不是怀孕，是被同一个东西寄生了
- 单条结论：女儿国不是国家，而是一个以子母河为介质的旧日神胚胎孵化容器。

## 4. 60-90 秒口播脚本

### 0-3 秒：事故结论

取经队进入女儿国后，只有猪八戒的影子逃了出来。

### 3-10 秒：经典设定反转

原著里，女儿国最可怕的是子母河。喝一口水，男人也会怀孕。

但这份残缺档案里写的不是怀孕，而是四个字：同源寄生。

### 10-22 秒：第一份证据，唐僧念错经

事故发生在御花园夜宴之后。

唐僧被请入正殿，为女王诵一卷安胎经。可沙僧后来回忆，那卷经书不是从包袱里取出来的。

它原本就放在王座下面。

第一页还正常，第二页开始，所有经文都变成了黑色螺旋。唐僧只念错了一个字，殿里的烛火就全部变成了绿色。

### 22-38 秒：第二份证据，子母河异常

悟空第一时间去查子母河。

水面没有倒映天空，只倒映出一片黑色海底。河里的莲花也不是植物，花瓣背面长满了像眼睛一样的孔。

最怪的是检测记录。

样本里没有胎儿细胞，只有一种不断重复分裂的未知胚层。所有人的胚层编号完全一致。

这说明她们怀的不是孩子。

是同一个东西的不同部分。

### 38-55 秒：第三份证据，悟空失效

悟空打碎了王宫里的照妖镜。

镜子里没有妖气，只有一串收容编号：WKG-013。

金箍第一次出现报警。不是因为唐僧遇险，而是因为金箍检测到师徒四人的影子数量不对。

唐僧一个影子。

沙僧两个影子。

白龙马没有影子。

猪八戒的影子，正在跪着喝子母河的水。

### 55-72 秒：事故升级

当晚三更，女儿国所有宫灯同时熄灭。

宫女们站在城墙上，对着西方一起诵经。她们念的不是佛经，是唐僧白天念错的那一页。

每念一遍，城里的孕相就同步加深一寸。

直到国王腹部传出第五个人的声音：

别去西天。

那里只是另一个子宫。

### 72-88 秒：结尾抬升

所以女儿国从来不是一场艳遇劫。

它更像一个古老孵化器。子母河负责播种，经书负责唤醒，取经人负责把胚胎带去西天。

而真正逃出来的，可能不是猪八戒。

是已经学会变成影子的那一部分。

## 8. 剪辑结构

- 开头 3 秒：事故结论 + 红色档案字卡
- 3-12 秒：经典设定反转，快速解释“怀孕不是怀孕”
- 12-52 秒：三份证据连续推进
- 52-68 秒：影子异常，制造记忆点
- 68-88 秒：国王腹部声音 + 世界观抬升

## 9. 字幕系统

- 主字幕：短句，白色，单行优先
- 高亮词：同源寄生、WKG-013、子母河、影子数量不对、另一个子宫
- 档案标注：E-001 经书残页，E-002 子母河水样，E-003 照妖镜碎片，E-004 影子异常
- 屏幕叠层：红框、时间码、样本编号、故障雪花

## 10. 音频设计

- 底噪：低频水压声 + 微弱胎心
- 经典元素：木鱼、诵经、人声合唱
- 异常元素：电子警报、仪器蜂鸣、反向人声、粘液声
- 结尾：女声低语“别去西天”，随后低频骤停

## 11. API 生成成本估算

### 不含真视频生成

- 生图：12-18 张，约 0.47-0.70 美元
- 重生成损耗：约 30%，合计 0.60-0.90 美元
- TTS：约 1000-1500 字，约 0.02-0.05 美元
- 文案/提示词 LLM：约 0.02-0.10 美元
- 合计：约 0.70-1.10 美元

### 加少量真视频生成

- 4-6 段关键动态，每段 4-5 秒，共 20-30 秒
- 按 0.10 美元/秒估算：2.00-3.00 美元
- 合计：约 3.00-4.50 美元

先不全片视频生成。第一版只做：
